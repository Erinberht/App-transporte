# Datos de ejemplo (FICTICIOS)

Los códigos y nombres de las rutas son los de Metrosinú. **Las paradas, coordenadas, recorridos y horarios son inventados** para desarrollar la app y no sirven para viajar.

Para regenerar `src/data/dataset.json` después de editar estos CSV:

```bash
npm run data:seed
```

Formato y cómo cargar datos reales: [`docs/DATA_MODEL.md`](../../docs/DATA_MODEL.md).
